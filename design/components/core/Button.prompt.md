Action button for docs pages and CLI-adjacent surfaces (install CTAs, "View on GitHub", form submits).

```jsx
<Button variant="primary">npm install --global xerify</Button>
<Button variant="secondary" size="sm">View on GitHub</Button>
```

Variants: `primary` (solid ink, for the one main action), `secondary` (outlined), `ghost` (text-only, for tertiary links inside toolbars). Never colored with the green accent — green is reserved for verification/success meaning.
