## Surface map

Xerify has no GUI application. The reusable design surfaces are the README/docs presentation,
terminal examples, command tables, verdict states, and MCP configuration examples. The
`ui_kits/docs-site/` page is a portable prototype for those surfaces, not a shipped runtime.

Provider examples must use exact configured model IDs or the literal `MODEL_ID` placeholder. Public
copy describes a bounded cross-provider second opinion and does not claim independent truth.
