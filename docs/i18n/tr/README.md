# Xerify dokümantasyonu

> Belgelerin normatif ve kanonik kaynağı İngilizce dokümantasyondur. Bir çeviri ile test edilmiş sözleşme çelişirse, geçerli olan taraf test edilmiş İngilizce sözleşmedir.

İngilizce; genel şemalar, ADR'ler, güvenlik politikası ve değişmez doğrulama kanıtları için temel dildir. Yerelleştirilmiş kılavuzlar, komut adlarına, JSON alanlarına, sağlayıcı/model tanımlayıcılarına, çıkış kodlarına ve yapılandırma anahtarlarına dokunmadan tüketici iş akışının tamamını anlatır. Bir çeviri ile test edilmiş bir sözleşme uyuşmazsa kazanan taraf test edilmiş İngilizce sözleşmedir; böyle bir sapmayı fark ederseniz lütfen bildirin.
